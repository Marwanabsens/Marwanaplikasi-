Identitas Instansi

Daftar nama memudahkan pemilihan saat mengisi absensi. Nama baru dari absensi juga akan masuk daftar otomatis.

Verifikasi Identitas Wajah

Model verifikasi wajah dimuat dari internet. Buka aplikasi dengan koneksi internet.

Daftarkan satu foto referensi untuk setiap orang. Saat absensi, aplikasi membandingkan selfie dengan referensi tersebut. Data template wajah disimpan di browser perangkat ini.

Belum ada pendaftaran wajah yang dilakukan.
Privasi: data wajah adalah data biometrik sensitif. Minta persetujuan orang yang didaftarkan, batasi akses perangkat, dan hapus template jika tidak diperlukan. Fitur ini membandingkan kemiripan wajah, tetapi tidak menjamin anti-spoofing/liveness dan dapat salah menolak atau menerima.

Pengaturan Zona GPS (opsional)

Isi koordinat titik lokasi resmi dan radius dalam meter jika absensi harus dilakukan di area tertentu. Kosongkan koordinat untuk menonaktifkan pembatasan zona.

Catatan Keamanan

Versi HTML ini menyimpan data di browser/perangkat yang digunakan. Data tidak otomatis terkirim ke admin atau tersinkron antar-HP. Pengguna dapat mengubah jam/perangkat dan data lokal; untuk sistem resmi multi-pengguna dibutuhkan server dan akun.

Cadangkan & Pulihkan Data

Unduh salinan seluruh catatan dan pengaturan secara berkala. Simpan file cadangan di tempat aman.

CSV cocok untuk membuka rekap di Excel atau Google Sheets. JSON menyimpan data lengkap agar dapat dipulihkan kembali.

Tindakan hapus tidak dapat dibatalkan. Unduh cadangan terlebih dahulu.
